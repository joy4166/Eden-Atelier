# E:DEN Digital Atelier

**(주)이든건축사사무소(대표건축사 강진호)**의 건축 AI · MCP 워크플로우와 대표 건축작 9선을 건축가의 책상 위 3D 미니어처 디오라마로 구현한 인터랙티브 WebGL 아틀리에입니다.

> **"건축(E:)을 담다(DEN)"** — 청사진이 펼쳐지며 시공되는 미니어처 건축 단지와 오픈형 쇼케이스 장식장을 3D 공간 안에서 자유롭게 탐색할 수 있습니다.

### 주요 인터랙션 & 디테일
- **청사진 시트 & 조건값 실시간 치환**: 대지 조건이나 행정구역 코드를 입력하면 프롬프트/JSON 본문에 즉시 반영됩니다.
- **`APPROVED` 도장 애니메이션**: 프롬프트, JSON 설정, 실습 샘플 또는 작품 제원을 복사하면 시트 위에 붉은 `APPROVED` 도장이 충격파와 함께 찍힙니다.
- **라이트모드 / 다크모드 & 스탠드 조명**: 상단 버튼 또는 3D 데스크 스탠드를 클릭하면 주간 자연광 ↔ 야간 스탠드 조명(갓 내부 발광, 소프트 볼륨 셰이더, 건물 창호 점등)으로 전환됩니다.
- **3×3 대표 건축작 장식장**: 각 칸을 선택하면 해당 건축 모형으로 카메라가 클로즈업되며 전용 스포트라이트와 제원 시트가 열립니다.

## 대표 건축작 9선 (`ARC-01` ~ `ARC-09`)

1. **Breath Taking** (`2024 경상북도 건축문화상 우수상`) — 경북 포항시 북구 여남동 · 제2종근린생활시설
2. **POETIES (포이티스)** (`2022 제14회 포항시 건축문화상 우수상`) — 경북 포항시 북구 환호동 · 제2종근린생활시설
3. **구름 속 산책** (`2021 제13회 포항시 건축문화상 우수상`) — 경북 포항시 남구 이동 · 단독주택
4. **소행성K** (`2018 제11회 포항시 건축문화상 장려상`) — 경북 포항시 · 단독주택 *(면적 정보: 공개 기록 없음)*
5. **Tan Tan Bi (탄탄비)** (`2024 준공`) — 경북 포항시 북구 기계면 · 단독주택
6. **ONE MORE DAY** (`2023 준공`) — 경북 포항시 남구 지곡동 · 단독주택
7. **이순당 (耳順堂)** (`2023 준공`) — 경북 포항시 북구 청하면 · 단독주택
8. **LAYERED** (`2023 준공`) — 경북 포항시 남구 대잠동 · 제2종근린생활시설
9. **Double Triangle** (`2022 준공`) — 경북 포항시 북구 흥해읍 · 제2종근린생활시설

## 기술 스택

- **Framework**: Next.js 15 (App Router), React 19, TypeScript 5
- **3D / Shaders**: Three.js (`MeshToonMaterial`, Custom GLSL Ground & Soft Volumetric Light Shaders, Custom Ink-Outline & Tilt-Shift DoF Post-Processing)
- **Motion & Scroll**: Lenis Smooth Scroll, GSAP, CSS Keyframes
- **Styling**: Tailwind CSS (`day` / `night` semantic design tokens)

## 시작하기

### 요구 사항
- Node.js 18 이상
- npm

### 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행 (http://localhost:3000)
npm run dev

# 프로덕션 빌드 및 실행
npm run build
npm run start
```

### 유용한 URL 쿼리 옵션
- `?intro=skip`: 시공 인트로 애니메이션을 건너뛰고 바로 전경으로 진입
- `?stop=cabinet&cubby=0`: 장식장 `01 Breath Taking` 칸으로 바로 클로즈업 이동
